# Earth Online RPG / RPG Life Product Vision

## 1. 產品定位

Earth Online RPG / RPG Life 是一個 RPG 風格的人生導航系統。

它不是傳統遊戲，也不是單純的待辦清單、習慣追蹤器或日記工具。它的核心目標是：讓使用者感覺自己正在走一段可以被看見、被推進、被回顧的人生旅程。

## 2. 核心價值

人生是一個長期遊戲。

使用者的人生可以被理解成由主線任務、支線任務、每日行動、重要事件與成長紀錄共同構成的旅程。

這個產品要幫助使用者做到三件事：

1. 看見自己正在走哪條路
2. 推進現實生活中的重要事情
3. 回顧自己曾經經歷與完成過的事情

## 3. 設計原則

### 可視化

重要事件、主線任務與人生階段應該被視覺化呈現在地圖或旅程路線上，而不是只存在於清單裡。

### 易用

使用者應該可以很快記錄一件事、推進一個任務、完成一個每日行動。操作不能太重，否則會變成負擔。

### 自由度

不同人的人生結構不同。產品不應該強迫所有事情都放在同一條路線上，也不應該用太固定的分類限制使用者。

## 4. 非目標

這個產品目前不是：

- 社群平台
- 多人遊戲
- 排行榜系統
- 單純 Todo App
- 單純 Habit Tracker
- 單純 Journal App
- 以等級、稱號、虛榮成就為主的遊戲化工具

RPG 是呈現風格，不是產品本體。

## 5. 目前最小閉環

目前核心閉環是：

Main Quest → Phase → Daily Action → Event → Progress → Review

也就是：

使用者建立一個主線任務，將它拆成階段，透過每日行動推進，完成後留下事件與進度紀錄，最後可以回顧自己走過的旅程。

## 6. 當前產品方向

目前優先改善的方向是：

1. Life Worlds / World Map 的視覺表現
2. 任務完成與推進時的回饋感
3. Main Quest 進度更新的便利性
4. 新使用者第一分鐘體驗，避免空白地圖
5. 長期回顧時的旅程感

## 7. 判斷功能是否值得做的標準

任何新功能都應該問：

1. 它是否讓人生旅程更可視化？
2. 它是否幫助使用者推進現實生活？
3. 它是否幫助使用者留下可回顧的紀錄？
4. 它是否增加太多操作負擔？
5. 它是否會讓產品變成普通 Todo、Habit 或 Journal App？

如果一個功能只是好看，但不能推進上述核心價值，應該延後。
